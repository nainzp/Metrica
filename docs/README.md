# MÉTRICA — Paquete de requerimientos

Contenido de esta carpeta:

- `docs/REQUERIMIENTOS_METRICA.md` — Documento de requerimientos del sistema (para Claude Code / equipo de desarrollo). Modelo de datos, reglas de negocio, cálculos, casos de uso, historias de usuario, API, importador, notificaciones, stack, despliegue en Windows Server 2019, plan de 7 días y requisitos no funcionales.
- `docs/Alcance_Funcional_METRICA_v2.docx` — Documento de alcance funcional en formato corporativo INGNOVATICS (versión 2.0, reemplaza al del 7 de septiembre).
- `docs/Presentacion_Funcional_METRICA.pptx` — Presentación funcional para la Secretaria y los líderes de área (14 láminas con notas del orador).
- `datos/Metas_Plan_Salud.xlsx` — Excel del Plan de Acción en Salud (hoja `PLAN`), carga inicial real del sistema.

Para iniciar el desarrollo con Claude Code: abrir esta carpeta en VS Code y pedirle que lea `docs/REQUERIMIENTOS_METRICA.md` completo y siga la sección 0 (guía rápida) y la sección 13 (plan de construcción).
